# Krok 1 – Náhodný příklad

```python
print(vytvor_priklad())     # {'a': 4, 'b': 6, 'vysledek': 24}
```

## Funkce

Napiš funkci `vytvor_priklad`. Nemá žádný vstup a vrátí slovník se dvěma
náhodnými čísly od 1 do 9 a jejich součinem.

Náhodné číslo dá `randrange` z lekce 4. Import je v souboru `nasobilka.py`
už nahoře.

## Program

Pod funkci napiš volání z ukázky a program spusť několikrát. Čísla budou
pokaždé jiná.

## Hotovo, když

- [ ] slovník má klíče `a`, `b` a `vysledek`
- [ ] čísla jsou od 1 do 9, včetně devítky
- [ ] `vysledek` je opravdu součin `a` a `b`
