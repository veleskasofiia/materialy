# Bonus 1 – Pruh

```python
print(pruh(30))     # ■■■
print(pruh(85))     # ■■■■■■■■
print(pruh(5))      # (prázdný text)
```

Výsledek se líp čte jako obrázek. Napiš funkci `pruh`, která z procent udělá
pruh: jeden čtvereček za každých celých 10 %. Pak pruh vypiš pod výsledek hry.

- Znak `■` si zkopíruj, nebo použij `X`.
- Text se dá opakovat násobením: `"■" * 3` je `"■■■"`.
- Procenta můžou být desetinné číslo a text desetinným číslem násobit nejde.
